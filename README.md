# DESIGN FOR AN OPEN MIND — Experimental UI/UX Interactive Website

> An interactive digital art exhibition exploring human cognition, neural connections, cognitive biases, and the transformative power of perspective.
> Created for UI/UX Design Competition 2026.

---

## 🌌 The Narrative Journey

```
BRAIN ➔ NEURONS ➔ CONNECTIONS ➔ PERCEPTION ➔ BIAS ➔ BREAK ➔ REFRAME ➔ OPEN MIND
```

### 10 Cinematic Stages:
1. **01 // THE MIND:** Volumetric 3D semi-transparent rotating brain with subtle breathing pulsation and floating orbital thought words.
2. **02 // NEURAL STATE:** Synaptic zoom into microscopic neural pathways with a staggered sensory pipeline (`SEE` $	o$ `PROCESS` $	o$ `CONNECT` $	o$ `THINK`).
3. **03 // THE CONNECTION:** Full-screen interactive living neural web where cursor movement sparks electrical signals across conceptual badges.
4. **04 // THE FILTER (PERCEPTION):** Interactive optical refraction shader lens with dynamic aberration and chromatic distortion on cursor hover/drag.
5. **05 // THE BIAS:** Floating non-traditional thought fragments with interactive cyber-text decoding and insight reveals.
6. **06 // BREAK THE PATTERN (The WOW Moment):** Neural instability, chromatic aberration, and particle deconstruction of the brain into floating fragments.
7. **07 // REFRAME:** Dispersed particles reassemble into a higher-order geometric constellation (`SAME PIECES. NEW CONNECTIONS.`).
8. **08 // OPEN MIND:** Infinite glowing neural constellation spanning the screen in Electric Cyan, Deep Violet, and Aurora Acid Green.
9. **09 // FINAL STATEMENT:** Minimal cinematic void with drifting neural dust.
10. **10 // THE MINDS BEHIND THE MIND:** Futuristic neural node cards for **Supriya Karmakar** and **Trijusha Sarbajna** linked by an animated energetic synaptic electrical arc.

## 🛠️ Tech Stack & Architecture

- **3D Engine:** Three.js r128 (Volumetric particle cloud + Catmull-Rom synaptic curves + ACES Filmic Tone Mapping)
- **Animation & Scroll Orchestration:** GSAP 3.12 + ScrollTrigger
- **Audio Synthesizer:** Web Audio API procedural binaural drone (110Hz alpha frequency) + FM synaptic feedback
- **Styling:** Tailwind CSS Play CDN + bespoke avant-garde CSS design system

## 🚀 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/design-for-an-open-mind.git

# Navigate to project folder
cd design-for-an-open-mind

# Start local server (Python)
python -m http.server 8080
```
Open `http://localhost:8080` in your web browser.
