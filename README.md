### ✨ 10 Cinematic Stages

| # | Stage | Motion Beat |
|---|-------|-------------|
| 01 | **THE MIND** | Volumetric 3D semi-transparent rotating brain, breathing pulsation, floating orbital thought words |
| 02 | **NEURAL STATE** | Synaptic zoom into microscopic pathways — staggered pipeline `SEE → PROCESS → CONNECT → THINK` |
| 03 | **THE CONNECTION** | Full-screen living neural web — cursor movement sparks electrical signals across conceptual badges |
| 04 | **THE FILTER (PERCEPTION)** | Interactive optical refraction shader lens with chromatic aberration on hover/drag |
| 05 | **THE BIAS** | Floating thought fragments with cyber-text decoding and insight reveals |
| 06 | **BREAK THE PATTERN** ⚡ *(the WOW moment)* | Neural instability, chromatic aberration, particle deconstruction of the brain |
| 07 | **REFRAME** | Dispersed particles reassemble into a higher-order constellation — `SAME PIECES. NEW CONNECTIONS.` |
| 08 | **OPEN MIND** | Infinite glowing neural constellation — Electric Cyan · Deep Violet · Aurora Acid Green |
| 09 | **FINAL STATEMENT** | Minimal cinematic void with drifting neural dust |
| 10 | **THE MINDS BEHIND THE MIND** | Futuristic node cards linked by an animated synaptic electrical arc |

### 🛠️ Tech Stack & Architecture

<div align="center">

![Three.js](https://img.shields.io/badge/Three.js%20r128-000000?style=for-the-badge&logo=three.js&logoColor=white)
![GSAP](https://img.shields.io/badge/GSAP%203.12-88CE02?style=for-the-badge&logo=greensock&logoColor=white)

- **3D Engine:** Three.js r128 — volumetric particle cloud, Catmull-Rom synaptic curves, ACES Filmic Tone Mapping
- **Animation & Scroll Orchestration:** GSAP 3.12 + ScrollTrigger — drives all 10 cinematic stage transitions
- **Audio Synthesizer:** Web Audio API procedural binaural drone (110Hz alpha frequency) + FM synaptic feedback
- **Styling:** Tailwind CSS Play CDN + bespoke avant-garde CSS design system

### 🚀 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/design-for-an-open-mind.git

# Navigate to project folder
cd design-for-an-open-mind

# Start local server (Python)
python -m http.server 8080
```

Open `http://localhost:8080` in your web browser.
